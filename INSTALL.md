# Установка Yumi-Rice 3.1

Рабочий стол на Hyprland + Quickshell: бар, меню, уведомления, экран блокировки и экран входа в цветах обоев.

## Требования

- **Arch Linux** или **Arch Linux ARM** (в том числе MacBook на Asahi). Другие дистрибутивы не поддерживаются.
- Обычный пользователь с `sudo` (установщик нельзя запускать от root).
- Интернет: пакеты из репозиториев, по желанию — из AUR (через `paru` или `yay`; если их нет, установщик предложит поставить `paru`).
- Hyprland **0.56 или новее** (конфиг на Lua) — ставится из `extra`.

## Установка

```zsh
git clone https://github.com/sonoyumi/yumi-rice.git && cd yumi-rice && ./install.sh
```

Сначала можно посмотреть, что будет сделано, ничего не меняя:

```zsh
./install.sh --dry-run
```

## Что спросит установщик

Каждый шаг — с вопросом `[y/N]` или `[Y/n]` (заглавная буква — ответ по умолчанию):

1. **Mac-модули** — только если найден MacBook (Asahi): заставка при загрузке, крышка, AirPods, слои тачбара.
2. **Бэкап** — без вопроса: всё, что будет перезаписано, копируется в `~/.local/state/yumi-rice/backup-ДАТА`.
3. **Пакеты** — основные (`packages/arch.txt`, на Mac ещё `packages/mac.txt`) и, по желанию, необязательные группы
   из `packages/optional.txt` (OCR, Logitech, Tailscale, Zen, VS Code, Telegram и т. д.).
4. **Файлы** — `./rice push` копирует конфиги и скрипты в домашнюю папку (публичная версия).
5. **Экран входа greetd** — файлы `/etc/greetd` (с показом разницы), автовход при загрузке (можно отказаться),
   папка `/var/lib/yumi-greeter`, выключение другого менеджера входа (SDDM, GDM…). greetd только **включается**:
   вход через него появится после перезагрузки.
6. **Остальные файлы `/etc`** (GRUB, zram, sysctl, earlyoom, Bluetooth, faillock) — по одному, с разницей.
   Они настроены под машину автора; если не уверены — отвечайте «нет».
7. **Плеер yumi-music** — своё окружение Python с yt-dlp и ytmusicapi.
8. **Службы пользователя** — `systemctl --user enable` для служб риса (запустятся при входе).
9. **Обои** — положите картинки в `~/Pictures/Wallpapers`; цвета всего стола берутся из них.
10. **Окно пароля** на Quickshell вместо hyprpolkitagent (`yumi-polkit-switch`).
11. **zsh** — oh-my-zsh с плагинами (по желанию) и zsh как оболочка по умолчанию.
12. **MacBook**: ссылки и шаги для Touch ID ([yumi-touchid](https://github.com/sonoyumi/yumi-touchid)) и тачбара —
    их установщик сам не ставит (нужно своё ядро и модули).

Повторный запуск безопасен: пакеты ставятся с `--needed`, уже применённое пропускается, каждый запуск делает свой бэкап.

## После установки

- Мониторы: `~/.config/yumi/monitors.conf`, для экрана входа — строки `output` в `~/.config/yumi/greeter/sway.conf`
  (имена выходов — из `hyprctl monitors`). Расположение мышью — `nwg-displays` (необязательный пакет).
- Аватар экрана блокировки: `~/.config/hypr/hyprlock/avatar.jpg`.
- Перезагрузка, затем проверка: `yumi-doctor`.

## Откат

```zsh
./install.sh --uninstall
```

Возвращает файлы домашней папки и `/etc` из бэкапов (для каждого файла — самая ранняя, исходная версия),
удаляет добавленные файлы, выключает включённые службы, возвращает прежний менеджер входа и штатное окно пароля.
Пакеты удаляются только по отдельному согласию. Бэкапы остаются в `~/.local/state/yumi-rice` — их удаляете вы.

Отдельные доработки откатываются и так: `yumi-uninstall` (список) и `yumi-uninstall <модуль>`.

## Известные ограничения

- Только Arch / Arch ARM: имена пакетов и `pacman` зашиты в установщик.
- Рис рассчитан на один или два монитора; имена выходов в `monitors.conf` и `greeter/sway.conf` надо поправить под себя.
- Системные файлы `/etc` (GRUB, Bluetooth с DeviceID Apple для AirPods) — с машины автора, применяйте осознанно.
- `awww` из `extra` — версия 0.12.1; у автора своя сборка с исправлением редкого падения демона обоев.
- Mac-части (Touch ID, тачбар, заставка загрузки) проверены только на MacBook Pro M1 13" (2020).
- Плеер работает с YouTube Music и SoundCloud без входа в аккаунт; свои плейлисты — `~/.config/yumi/music/playlists.json`.
- Оформление программ (VS Code, Zen, Telegram, Vesktop, Obsidian) включается, только если программа установлена.
